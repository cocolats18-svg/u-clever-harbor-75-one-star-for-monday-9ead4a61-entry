One Star for Monday: a single original line — a one-star review of Monday written as though Monday were a restaurant. Monday arrives at the table cold, the waiter overcooks the weekend, and the bill runs five working days long. 21 words, one line, plain text.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Node 22+ stdlib only, no network, no randomness — the same bytes every run.
